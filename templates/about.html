About VegFood Detector

Your trusted companion for vegetarian food detection

🎯 Our Mission

VegFood Detector was created to help vegetarians and people with peanut allergies make informed food choices. Our application quickly identifies whether food items are suitable for vegetarian diets and alerts users about potential peanut allergens.

✨ Features

  • Vegetarian Detection: Instantly check if a food item is vegetarian
  • Peanut Allergen Alert: Get warnings about peanut content
  • Food Categorization: Learn about food categories (vegetables, fruits, grains, etc.)
  • Easy to Use: Simple text-based interface for quick checks
  • API Access: RESTful API for developers to integrate into their apps

🔍 How It Works

Our system uses a comprehensive database of common food items categorized into vegetarian and non-vegetarian groups. When you enter a food name, we analyze it against our database to determine:

  • Whether it contains vegetarian or non-vegetarian ingredients
  • If it contains peanuts or peanut-based products
  • The food category it belongs to

🚀 Future Enhancements

We're constantly working to improve VegFood Detector. Upcoming features include:

  • AI-powered image recognition for food photos
  • Expanded food database with regional cuisines
  • Nutritional information display
  • User accounts and food history tracking
  • Mobile app development
  • Multi-language support

📚 API Documentation

Developers can integrate our detection system using our RESTful API:

POST /api/detect
Content-Type: application/json

{
  "food_name": "pizza"
}

Response:
{
  "food_name": "pizza",
  "is_vegetarian": true,
  "contains_peanut": false,
  "category": "others",
  "safe_for_veg": true,
  "allergen_warning": false
}

⚠️ Disclaimer

This application provides general guidance based on common food ingredients. Always check food labels and consult with the food provider for accurate information about ingredients and allergens. This tool should not be used as a sole source for making dietary decisions, especially for people with severe allergies.
